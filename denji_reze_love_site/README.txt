DENJI × REZE — Romantic mini-site

FILES
- index.html: complete responsive website (HTML, CSS, JavaScript in one file)

RUN LOCALLY
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Tap “Musiqini aç” once to enable the original ambient melody (browsers require a user gesture).

CUSTOMIZE
- In index.html, search for “Canım mənim” to edit the love letter.
- Replace “mənim adım” with your name or nickname.
- The character silhouettes and ambience are CSS-created, so the site works without downloading anime images.
- The melody is an original synthesized ambient pattern, not the Chainsaw Man soundtrack.

PUBLISH
Upload index.html to GitHub Pages, Netlify, or another static hosting provider.
